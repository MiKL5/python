<summary>Exécuter localement un projet</summary>

Python 3.11 ou 3.12 est requis. Chaque projet se lance depuis son propre dossier, dans un environnement virtuel dédié.

```bash
git clone [https://github.com/MiKL5/python.git](https://github.com/MiKL5/python.git)
cd python/mini_projects/fizz_buzz
python3 -m venv .venv
source .venv/bin/activate   # Windows : .venv\Scripts\activate
python3 main.py
```

Un projet qui importe une bibliothèque tierce (pandas, matplotlib, etc.) exige de préalablement l'installer via <code>python -m pip install `<paquet>`</code>. Lorsque le projet fournit un fichier `requirements.txt`, cette commande installe tout : <code>python -m pip install -r requirements.txt</code>.
